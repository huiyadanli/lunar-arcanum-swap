# 圣牌 Box 字母码 v1

实现位于 `src/lib/box-code.js`。字母码用于迁移收藏数据及选牌设置，不包含 UID、会话、账号、换牌需求或交换历史。

文本格式为纯字母数字串，无前缀。字符集为 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`（32 个，去掉易混淆的 0/O、1/I）。导入时忽略大小写和空白，拒绝非法字符、未知版本、截断、校验失败、越界数量和相互冲突的快速选牌。

按以下顺序写入位流；所有整数高位在前，所有牌序固定为 ID 1–22。

| 字段 | 位数 | 含义 |
|---|---|---|
| 版本 | 2 | 格式版本号，当前为 0（即第一版） |
| 快速块标志 | 1 | 1 表示包含快速交换块；给出和想要都为空时必须为 0 |
| “不想要”标记标志 | 1 | 1 表示包含“不想要”位图；`wantOff` 为空时必须为 0 |
| 当前模式 | 1 | 0 为完整 Box，1 为快速交换 |
| 保留张数 | 2 | 0–2 |
| 完整 Box 数量位宽 `c` | 3 | 0–4；选择能容纳最大张数的最小位宽，全零时为 0 |
| 完整 Box 数量 | `22 × c` | 每张牌 0–9；位宽为 0 时全部为 0 |
| 不想要标记 | 22 | 仅当“不想要”标志为 1；每种牌一位，1 表示位于 `wantOff` |
| 快速给出数量位宽 `q` | 3 | 仅当快速块标志为 1；0–4，最小位宽 |
| 快速给出数量 | `22 × q` | 仅当快速块标志为 1；每种牌 0–9 |
| 快速想要标记 | 22 | 仅当快速块标志为 1；同一种牌不能同时给出和想要 |
| CRC-10 | 10 | 对此前全部有效数据位计算，初值 `0x3FF`，多项式 `0x233`（x^10+x^9+x^5+x^4+x+1），不反转、不填充字节、不做末尾异或 |

在位流最高位补一个值为 1 的哨兵，把整体视为无符号大整数，以 32 为基数转换为字符串（每字符 5 位）。哨兵用于保留原始前导零。导入执行逆变换，去掉哨兵后先核验 CRC，再读取各字段，并要求位流恰好读完、位宽为最小值。有效数据与校验共 20–243 位，字符串 5–49 个字符；典型 Box（数量 0–3、无快速块、无“不想要”）约 15 个字符。

数量上限为 9；超过 9 的 Box 无法导出。CRC-10 能检出长度不超过 10 位的突发错误，因此任意单个字符写错、任意相邻两个字符颠倒都必然被发现；其余随机损坏有约 1/1024 的漏检概率，再由位宽最小化、位流恰好读完等结构检查进一步拦截。CRC 不作为登录凭据或签名。

## 界面

「我的 → 导出圣牌 Box」显示并复制字母码。「导入圣牌 Box」在粘贴时自动校验并显示识别结果，点击「导入并替换 Box」一次应用数量、保留数、想要标记、快速选牌及当前模式。输入无效时不修改本地数据；有进行中的交换时禁止导入。已有等待中的换牌需求保留，用户可在 Box 页手动更新。
