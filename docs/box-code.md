# 圣牌 Box 字母码 v1

实现位于 `src/lib/box-code.js`。字母码用于迁移收藏数据及选牌设置，不包含 UID、会话、账号、换牌需求或交换历史。

文本格式为 `LASB1-<A–Z 字母串>`。`LASB` 为魔数，`1` 为版本；导入时忽略大小写和空白，拒绝未知版本、非法字符、截断、校验失败、越界数量和相互冲突的快速选牌。不读取旧 JSON 文件。

按以下顺序写入位流；所有整数高位在前，所有牌序固定为 ID 1–22。

| 字段 | 位数 | 含义 |
|---|---|---|
| 完整 Box 数量位宽 `c` | 3 | 0–7；选择能容纳最大张数的最小位宽，全零时为 0 |
| 保留张数 | 2 | 0–2 |
| 当前模式 | 1 | 0 为完整 Box，1 为快速交换 |
| 完整 Box 数量 | `22 × c` | 每张牌 0–99；位宽为 0 时全部为 0 |
| 不想要标记 | 22 | 每种牌一位，1 表示位于 `wantOff` |
| 快速给出数量位宽 `q` | 3 | 0–4；按最大数量选择最小位宽，全零时为 0 |
| 快速给出数量 | `22 × q` | 每种牌 0–9 |
| 快速想要标记 | 22 | 每种牌一位；同一种牌不能同时给出和想要 |
| CRC-16 | 16 | 对此前全部有效数据位计算，初值 `0xFFFF`，多项式 `0x1021`，不反转、不填充字节、不做末尾异或 |

在位流最高位补一个值为 1 的哨兵，把整体视为无符号大整数，以 26 为基数转换为字母串，`A=0, B=1, …, Z=25`。哨兵用于保留原始前导零。导入执行逆变换，去掉哨兵后先核验 CRC，再读取各字段，并要求位流恰好读完、数量位宽为最小值。有效数据与校验共 69–311 位，字母串最多 67 个字符。

完整 Box 只有 0/1 时每张牌只占一位；重复牌按需增加位宽，保留准确数量。CRC 用于识别复制错误，不作为登录凭据或签名。

「我的 → 导出圣牌 Box」显示并复制字母码。「导入圣牌 Box」在粘贴时自动校验并显示识别结果，点击「导入并替换 Box」一次应用数量、保留数、想要标记、快速选牌及当前模式。输入无效时不修改本地数据；有进行中的交换时禁止导入。已有等待中的换牌需求保留，用户可在 Box 页手动更新。
