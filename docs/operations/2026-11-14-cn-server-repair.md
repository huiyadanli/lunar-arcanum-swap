# 2026-11-14 国服区服隔离与线上错误匹配修复

天空岛与世界树曾共用 `cn` 匹配池，导致不能互加好友的玩家被匹配到一起。此次按用户要求修正线上分区、解除错误匹配、恢复入池并撤销由此产生的冷却与结算影响。

## 已上线的规则

- 迁移 `20261115020000_separate_cn_servers` 已应用，保留业务数据及原有函数权限。
- 天空岛仍为 `cn`，世界树为 `cn_bili`；扫描同时校验双方实际 `server` 相同，维护覆盖全部六个分区。
- `swap-api` 已更新代码并确认处于 `Active`，环境变量与入口保持原配置。
- 世界树玩家、需求快照及世界树内部历史匹配均已归入独立分区。

## 数据修复结果

执行 `scripts/repair-cn-server-matches.sql` 前，先保存受影响记录和线上业务快照，并在本地 PostgreSQL 兼容运行时完整演练。备份放在 Git 忽略的 `.secrets/repairs/` 中，含私人 UID 和业务记录，不应提交或公开。

- 共发现并作废 19 条跨服错误记录，涉及 19 个账号：3 条未结束、14 条已失败、2 条曾被自动判为完成。
- 未结束的 3 条错误匹配已释放占用，双方共 6 条需求均处于等待池。
- 错误记录保留在历史中，使用现有 `disputed` 终态中性结算；页面会显示为争议记录，不再扣分，也不能再次确认成功。
- 已失败记录不重复返还卡牌；误判完成的记录撤销奖励与完成次数，只对仍在使用原轮次的需求恢复相关卡牌。已有新轮次、UID 已变更或已有正常完成记录的库存不被覆盖。
- 19 个受影响账号的发布冷却截止时间已清空，恢复主动发布机会。信用由冲正后的流水重新计算，仅撤销错误匹配造成的处罚，正常同服处罚保留。核查时这些账号没有尚在生效的信用处罚冷却。
- 2 个账号各恢复被错误扣除的 15 信用分；4 个账号由误判完成获得的奖励与各 1 次完成数已撤销。
- 由错误匹配建立的双方屏蔽已移除；幂等键保留，并更新缓存中的旧资料、需求和结算结果。

## 验证

线上复核：跨服有效匹配为 0，19 条错误记录均已中性结算，错误信用流水影响为 0，受影响账号残留发布冷却为 0，世界树玩家与需求的分区错误为 0；23 名世界树玩家的分区均正确。卡牌占用与仍有效的匹配逐条核对一致，维护到期索引已重新同步。

修复 SQL 在单个事务中按业务规则获取 `cn`、`cn_bili` 分区锁。后续重跑仅处理尚未作废的跨服错误记录，不会取消用户修复后新产生的正常发布冷却。
