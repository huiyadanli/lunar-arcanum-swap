# 月谕圣牌交换站

**更好的原神 · 月谕圣牌交换站**，隶属于 [BetterGI](https://github.com/babalae/better-genshin-impact) 项目。

> 🌙 连接月下的收藏者，让多余成为彼此的惊喜。

选出你多余和想要的月谕圣牌，自动寻找能互换的玩家，匹配后在游戏内通过「月谕之匣」完成交换。站点只负责牵线，不经手游戏内物品，也不需要你的游戏账号密码。

## ✨ 核心功能与亮点

- **自动匹配**：按双方供需寻找同服务器的换牌伙伴，1 换 1 互换。
- **快速交换 / 完整 Box**：随手选几张就能发布需求，也可管理全部 22 种圣牌，查看收藏进度。
- **图片导入**：识别米游社导出的圣牌收藏图，减少手动录入；图片在本机处理，不上传。
- **交换名片**：将换牌需求生成带二维码的图片，方便分享到群聊和社区。
- **UID 保护**：开始交换前隐藏完整 UID，确认开始后再联系对方。
- **Box 备份**：通过短码备份收藏，在不同设备间迁移。

## 🚀 开始交换

填写 UID → 选好「我能给出」和「我想要」→ 发布需求 → 匹配后到游戏内交换。

仅支持同一服务器的玩家互相匹配，**天空岛与世界树不互通**。

## 💻 本地运行

需要 Node.js 20.19+（或 22.12+）和 npm，本地开发默认使用模拟数据。

```bash
npm install
npm run dev
# 打开终端显示的地址，默认 http://localhost:5173/
```

运行 `npm run build` 生成前端构建产物，输出目录为 `dist/`。
