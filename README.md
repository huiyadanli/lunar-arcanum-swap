# 月谕圣牌交换站

**更好的原神 · 月谕圣牌交换站**，隶属于 [BetterGI](https://github.com/babalae/better-genshin-impact) 项目。

> 🌙 连接月下的收藏者，让多余成为彼此的惊喜。

告诉站点你多出哪些月谕圣牌、想要哪些，站点帮你找到正好能互换的玩家；匹配成功后，双方在游戏里通过「月谕之匣」完成交换。**站点只负责牵线，不经手任何游戏内物品，也不需要你的游戏账号密码。**

---

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 圣牌 Box | 记录 22 种圣牌的持有数量，查看月相收集进度 |
| 快速交换 | 不整理 Box，只选「我能给出」和「我想要」，立刻开换 |
| 自动匹配 | 同服务器内自动寻找能 1 换 1 互换的伙伴 |
| UID 保护 | 开始交换之前，双方 UID 全程脱敏 |
| 交换名片 | 一键生成带二维码的图片，分享到群聊和社区 |
| 图片导入 | 导入米游社导出的圣牌收藏图，自动识别数量（本机处理，不上传） |
| Box 字母码 | 一串短码即可备份、迁移整个 Box |
| 双语 | 简体中文 / English |

## 🚀 快速开始

### 1. 填写 UID

首次打开时，输入你的原神 UID（9 或 10 位数字）。站点会自动识别服务器：

| 服务器 | 说明 |
|---|---|
| 天空岛 / 世界树 | 国服，两者互通 |
| 亚服 / 美服 / 欧服 / 港澳台服 | 国际服 |

只有**同一分区**的玩家才会互相匹配，因为跨服无法加好友。

### 2. 选择使用方式

- **快速交换**：只选几张牌，马上开换，适合偶尔换一两张。
- **整理完整 Box**：记录全部 22 种牌的数量，适合长期使用。

两种方式的选牌互不影响，可随时在 Box 页顶部切换。

### 3. 选牌并发布

选好要给出和想要的牌，点击 **「帮我找人换牌」**，确认后即进入交换页等待匹配。

## 📖 使用指南

### 🃏 我的 Box

**完整 Box 模式**

- 22 张牌排成网格，顶部显示收藏进度和「缺 / 可换」统计。
- 每张牌有四种状态：**缺少**、**持有**、**可换**（带 +N 标记）、**交换中**（已被当前交换占用，暂时不可修改）。
- 点击卡牌打开详情抽屉：可调整持有数量、设置是否「想要这张」。抽屉里可以左右滑动切换到上一张 / 下一张，长按加减按钮可连续增减。
- 点击右上角 **「批量」** 可以快速录入多张牌的数量。
- 用筛选条在 **全部 / 缺少 / 可换** 之间切换。
- 「可换」数量 = 持有数量 − 保留张数。每种牌默认自留 1 张，可在「我的」里改为 0、1 或 2 张。
- 已拥有的牌不能加入「想要」；集齐 22 种时会播放满月动画。

**快速交换模式**

- 分为「我能给出」和「我想要」两个标签。
- 点一下牌加入选择，再点一下数量 +1，**长按**则移除。
- 同一张牌不能同时出现在「给出」和「想要」里，会有提示。
- 底部栏实时显示「X 张可换 · Y 张想要」。

### 📝 发布换牌需求

点击「帮我找人换牌」后会出现确认抽屉：

- 可以选择**一条预设留言**或**一个有空的换牌时间段**（如 20 点后在线、周末全天在线、08–12 等），再点一次可取消。
- 出于安全考虑，**不支持自由输入文字**，对方会按自己的语言看到你的选择。
- 留言和时间段仅在匹配成功后对方才可见。

发布后：

- 同时只能有一条有效的换牌需求。
- 发布后需要**冷却一段时间**才能再次发布或重新匹配：B站登录用户 1 分钟，匿名用户 20 分钟。**撤回需求**或**交换成功**后冷却会立即清除。
- 等待期间可以随时 **编辑** 或 **撤回** 需求；编辑不计入冷却。
- 点击 **「重新匹配」** 可主动再找一轮。

### 🌙 交换页

「交换」页分三块：

- **我的换牌需求**：当前等待状态、你所在服务器正在等待的人数、你想要的牌是否稀缺，以及编辑 / 撤回 / 重新匹配入口。
- **待完成的交换**：已经匹配成功、需要你处理的交换。
- **历史记录**：已结束的交换（对方 UID 始终脱敏）。

交换页有新匹配时，底部「交换」标签上会出现角标。页面会自动刷新，无需手动操作；切回页面时也会立即更新。

## 🔄 交换流程

```
发布需求 → 匹配成功 → 开始交换 → 加好友 → 游戏内交换 → 确认结果
```

### 🎉 匹配成功

- 匹配成功时有一段揭晓动画，点击可跳过。
- 一次匹配包含 **1 到 3 对**「你给 X ⇄ 你得 Y」，每对均为严格 **1 换 1**。
- 匹配成立后 **48 小时** 内有效，被匹配的卡牌会自动预留，期间不可修改。
- 匹配详情里能看到交换对象的信用等级（月亮图标）、交换内容和剩余时间。

### 🔓 开始交换

- 点击 **「开始交换」** 后才会显示对方的完整 UID（以逐位解码动画呈现）。点击后无法撤回，对方也会看到「对方已开始交换」。
- B站用户首次点击时，若还没有关注 UP主，会先引导关注，关注后自动继续。
- 不想换了可选择「不换了」。

### 🤝 加好友并交换

1. 点击「复制 UID」，在游戏里添加对方为好友；也可以点「复制好友申请留言」，粘贴到申请备注，对方一看就知道是为了换牌（例如：`换月谕圣牌：我给你「星」，换你的「塔」`）。
2. 对方在线时，也可以不加好友，直接进入对方世界交换。
3. 在游戏里通过 **「月谕之匣」** 向对方发起交换「月谕圣牌」的邀请，消耗自己多余的圣牌，与对方 1:1 互换。

### ✅ 确认结果

回到站点，选择：

- **确认交换完成**：如果一次匹配有多对，可以勾选实际完成了哪几对。确认后你的 Box 会自动更新（可撤销）。
- **遇到问题**：选择原因（对方没有加我 / 对方没有回应 / 对方手里没有这张牌了 / 对方不想换了 / 我自己无法完成 / 其他）。如果问题出在对方身上，你的需求会自动放回匹配池，且不触发发布冷却。

**注意**：任何一方点击确认完成后，对方有 **10 分钟** 时间确认；超时未响应将自动按成功处理。双方都确认完成后，你会立即恢复一次发布额度，可以马上发起新一轮。

### 🌕 信用

每个账号都有信用等级，以月亮数量显示。正常完成交换会提升信用，爽约、无回应等会降低信用；信用过低时将暂时无法参与匹配。

## 🪪 交换名片

选好「给出」和「想要」两组牌后，点击 **「制作交换名片」**，即可生成一张图片名片，展示：

- 卡面、名称和可换数量
- 服务器与生成日期
- 站点二维码（扫码直接打开本站）

使用说明：

- 在「我的 Box」里和「交换 → 我的换牌需求」里都可以生成名片。前者无需先发布需求。
- UID 默认显示在名片上，方便对方直接加好友；可在预览中**一键隐藏**。
- 名片是 1080px 宽的 JPG，牌多时自动加长，体积控制在 600 KB 左右。
- 在 B站 App 内点击保存会存入相册，也可直接分享；其他环境会下载图片，手机上也可以长按预览图保存。
- 名片只包含站点入口，不含登录凭据。

名片页还提供 **文本版**，不方便发图时可以直接复制文字发给对方。

## 🖼️ 从图片导入 Box

不想一张张录入？可以导入米游社导出的收藏图。

### 📤 导出图片

米游社 App → 个人主页 → 原神卡片 → 向下滑动 → 点「月谕圣牌」收藏 → 右上角分享 → 保存图片。请导出**完整的收藏长图**，不要裁剪或加滤镜。

### 📥 导入图片

1. 进入「我的 Box → 从图片导入 Box」（或「我的 → 从图片导入 Box」）。
2. 选择图片，也可以直接**拖进窗口**，或按 **Ctrl+V** 粘贴截图。
3. 站点在本机自动识别每张牌的 0 / 1 / 2 张，并展示 22 张牌的「当前数量 → 导入数量」。
4. 逐张核对。数量不确定的牌会标为「待确认」，可手动填 0–99，也可展开原图局部对照，或选择「保留当前数量」。
5. 如果识别区域不对，展开 **「调整识别区域或牌序」**：在原图上框选牌区，指定每行列数和首行最左边是哪张牌，然后重新识别。
6. 确认无误后点击 **「导入并替换 Box」**。

说明：

- **图片只在你的浏览器里处理**，不会上传到任何地方，也不会读取或保存图片里的 UID。
- 导入会**替换**现有数量（不是相加），并切换到完整 Box 模式；保留张数、想要标记等个人设置不会受影响。
- 识别过程中可随时停止、换图或关闭。
- 有进行中的交换时不能导入；已发布的换牌需求需要手动更新。

## 🔤 Box 字母码

字母码是一串由字母和数字组成的短码，可以在不同设备之间迁移或备份你的 Box。

- **导出**：「我的 → 导出圣牌 Box」，点击复制。
- **导入**：「我的 → 导入圣牌 Box」，粘贴即可自动识别并校验，确认后点击「导入并替换 Box」。

字母码包含 22 种牌的数量（每种 0–9）、保留张数、想要标记、快速交换的选牌和当前模式，**不包含身份信息或交换记录**。有进行中的交换时不能导入。

## 👤 我的

- **账号卡片**：显示账号类型（B站 / 匿名）、同步状态和信用。
- **语言**：中文 / English 切换。
- **特效**：一键开关。开启后站点会根据设备性能自动选择画质，运行中持续卡顿会自动降档。偏好「减少动态效果」的设备默认关闭。
- **保留张数**：每种牌自留 0 / 1 / 2 张。
- **修改 UID**：有已发布的换牌需求时修改 UID 会撤回该需求，会先弹出确认。
- **导出 / 导入 Box**、**从图片导入 Box**。
- **电脑扫码继续**：在电脑上打开时，可用 B站 App 扫码在手机上继续。
- **清除本地数据**：清空本设备数据（B站用户还可选择同时清除云端数据）。

## 💻 本地运行

需要 Node.js 20.19+（或 22.12+）和 npm。

```bash
npm install
npm run dev
# 打开终端显示的地址，默认 http://localhost:5173/
```

本地开发使用模拟数据。打开页面左边缘（PC 为右边缘）的调试把手，可以切换 B站 / 匿名用户、模拟匹配和对方的操作、清除冷却。

也可以用地址参数直接切换：

| 地址 | 效果 |
|---|---|
| `/?mock=anon` | 匿名用户 |
| `/?mock=bili` | B站 App 内的 B站用户 |
| `/?env=toy-web` | B站网页端 |

## 📦 构建与部署

```bash
npm run build
```

构建产物在 `dist/`，是纯静态文件，上传到任意静态托管服务即可使用，支持根目录和子目录部署。页面使用 `#/` 形式的路由，不需要服务器额外配置；需通过 HTTP(S) 访问，不能直接双击打开。
